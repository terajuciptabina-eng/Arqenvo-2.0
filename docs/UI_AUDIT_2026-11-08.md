## Source-audit findings
- `index.html` provides a three-column workspace and semantic application shell.
- `src/app/main.mjs` draws the 2D plan and an isometric derived 3D preview on a 2D canvas; this is not a true interactive 3D CAD viewport.
- Canvas interaction uses Pointer Events and `touch-action: none`; keyboard shortcuts include Enter to finish chain dimensions and Escape to cancel.
- Persistence uses IndexedDB with memory fallback.
- `src/app/app.css` hides the entire inspector at `max-width: 900px`. This removes access to wall/opening property editing on tablet and phone widths. It is a responsive UX limitation, not a geometry-kernel issue.
- The top toolbar uses compact text buttons which may crowd on narrow iPhone widths; physical device validation remains outstanding.

## Scope and limitations
- Screenshot is a user-provided Safari desktop screenshot. It does not establish physical iPad/iPhone behavior.
- No claim of Archicad 29 parity.
- No production geometry kernel selected.
- No change to geometry algorithms or modelling behavior was made as part of this UI audit.
